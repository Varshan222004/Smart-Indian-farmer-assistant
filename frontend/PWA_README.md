# Progressive Web App (PWA) Setup

This project has been configured as a Progressive Web Application (PWA), allowing users to install it on their devices and use it offline.

## Features

✅ **Installable** - Users can install the app on their home screen  
✅ **Offline Support** - Cached content works offline  
✅ **App-like Experience** - Standalone display mode  
✅ **Fast Loading** - Service worker caches assets for quick access  
✅ **Update Notifications** - Users are notified when new versions are available  

## Installation

### For Users

1. **On Mobile (Android/iOS):**
   - Open the app in Chrome/Safari
   - Look for the "Add to Home Screen" prompt or use the browser menu
   - Tap "Add to Home Screen"
   - The app will appear on your home screen like a native app

2. **On Desktop (Chrome/Edge):**
   - Visit the app in your browser
   - Look for the install icon in the address bar
   - Click "Install" to add the app to your desktop
   - Or use the install button that appears in the bottom-right corner

### For Developers

1. **Generate Icons:**
   ```bash
   npm run generate-icons
   ```
   This creates all required PWA icons in `public/icons/`

2. **Build for Production:**
   ```bash
   npm run build
   ```
   The service worker will be automatically generated during build.

3. **Test PWA Features:**
   - Build the app: `npm run build`
   - Preview: `npm run preview`
   - Open in browser and check:
     - Service worker is registered (DevTools > Application > Service Workers)
     - Manifest is valid (DevTools > Application > Manifest)
     - App can be installed
     - Offline functionality works

## Configuration

### Manifest
The app manifest is configured in `vite.config.js` under the `VitePWA` plugin. Key settings:
- **Name**: Smart Indian Farmer Assistant
- **Theme Color**: #16a34a (green)
- **Display Mode**: Standalone
- **Icons**: Multiple sizes for different devices

### Service Worker
The service worker is automatically generated by `vite-plugin-pwa` using Workbox. It includes:
- **Asset Caching**: All JS, CSS, HTML, and images
- **Runtime Caching**: 
  - Weather API (1 hour cache)
  - Google Translate (24 hour cache)
  - Backend API (5 minute cache)
  - Images (30 day cache)

### Offline Support
- Static assets are cached for offline access
- API responses are cached with appropriate expiration times
- Offline fallback page available at `/offline.html`

## Customization

### Icons
Replace the icons in `public/icons/` with your custom designs. Required sizes:
- 72x72, 96x96, 128x128, 144x144, 152x152, 192x192, 384x384, 512x512

### Theme Color
Update the `theme_color` in `vite.config.js` to match your brand.

### Caching Strategy
Modify the `runtimeCaching` rules in `vite.config.js` to adjust cache durations and strategies.

## Testing

### Chrome DevTools
1. Open DevTools (F12)
2. Go to **Application** tab
3. Check:
   - **Service Workers**: Should show registered worker
   - **Manifest**: Should show valid manifest
   - **Cache Storage**: Should show cached resources
   - **Lighthouse**: Run PWA audit

### Offline Testing
1. Open DevTools > Network tab
2. Enable "Offline" mode
3. Refresh the page
4. App should still work with cached content

## Troubleshooting

### Service Worker Not Registering
- Ensure you're using HTTPS (or localhost for development)
- Check browser console for errors
- Verify `vite-plugin-pwa` is installed

### Icons Not Showing
- Ensure icons exist in `public/icons/`
- Check manifest.json references correct paths
- Clear browser cache and reload

### App Not Installable
- Check manifest is valid (DevTools > Application > Manifest)
- Ensure service worker is registered
- Verify HTTPS is enabled (required for production)
